# 📸 Ауграм для ПК

Десктопное приложение Ауграм.

## 🚀 Возможности
- Просмотр удаленых сообщений
- Режим призрака
- Установка плагинов
- Большой выбор Кастомизации

## 🛠 Внимание!
Может Вызывать ложные срабатывания Антивируса

## 📦 Установка
Открой Установщик AyuGram Dekstop от имени администратора и ждите установку
